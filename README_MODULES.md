# Magist Module Repo Quick Reference (Android-first)

This repository is an index of modules and repositories organized by operating system so contributors and integrators can quickly find projects that will run in their environment.

Files in this repo:

- ANDROID.md — Android-focused quick reference and templates (primary/front‑runner)
- WINDOWS.md — Windows-focused quick reference and templates
- MACOS.md — macOS-focused quick reference and templates
- LINUX.md — Linux-focused quick reference and templates
- IOS.md — iOS-focused quick reference and templates
- DOCKER.md — Container/Docker-focused quick reference and templates
- MODULE_INDEX.json — Structured index for programmatic use (initially empty)
- LICENSE — MIT License
- README_MODULES.md — This top-level guide linking to OS-specific references

How this repo is organized
- Each OS has its own file with one module entry per header for easy browser Find (Ctrl/Cmd+F).
- Module entries include Supported Systems (Android first for Android entries), Per-system prerequisites, One-line install/run commands, Quick verification checks, Key files, Known limitations, and Attribution (link to original repo).

Contributing
- To add a module, open a PR that adds an entry under the relevant OS file (one entry per module, use the provided template in each OS file).
- If you prefer, open an issue with a repo URL and the per-system notes and a maintainer will add it.
